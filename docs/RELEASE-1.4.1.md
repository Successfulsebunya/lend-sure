# KuLoan Ledger 1.4.1 — Branding & WordPress.org Compliance

## Scope

Version 1.4.1 is a branding/compliance-only release following WordPress.org review feedback.

## Public identity

- Display name: **KuLoan Ledger**
- Requested WordPress.org permalink: `kuloan-ledger`
- Text domain: `kuloan-ledger`
- Version: `1.4.1`

## Backward compatibility

The established internal identifiers remain unchanged so existing installations keep their data and behavior:

- `LendSure_*` PHP classes
- `lendsure_*` custom database tables
- `lendsure_*` WordPress options
- `lendsure_*` actions/admin identifiers
- Existing borrower, loan, payment, transaction, reminder, acknowledgement, and settings data

## Functional scope

No lending calculations, payment allocation rules, reporting calculations, database schema, backup format, or destructive workflows are changed in this release.
